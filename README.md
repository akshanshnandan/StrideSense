# StrideSense

## Overview

StrideSense is a wearable running analytics system built using a Raspberry Pi Pico WH and a 6-axis IMU.

Its goal is to estimate running metrics such as

- cadence
- step count
- impact consistency

using embedded hardware and Python-based signal processing.

## Hardware

- Raspberry Pi Pico WH
- Adafruit MPU6050
- STEMMA QT cable

## Planned Features

- Read IMU data
- Save runs
- Analyze data
- Dashboard visualization
